╔══════════════════════════════════════════════════════════════════╗
║  SH-DATASET — Categorías y Subcategorías para Plugins          ║
║  Basado en Cyber Kill Chain (Lockheed Martin) + MITRE ATT&CK   ║
╚══════════════════════════════════════════════════════════════════╝

Al crear un plugin de ataque (.py), usar estos valores en los campos
kill_chain y subcategory del AttackDef:

    AttackDef(
        ...
        kill_chain="Reconnaissance",
        subcategory="network_scanning",
        mitre_ref="T1046",
        ...
    )

      AttackDef(
          name="mqtt_topic_bruteforce",
          description="Fuerza bruta de topics MQTT protegidos",

          requires_root=False,
          recommended_dur_s=60,
          continuous=True,
          kill_chain="Exploitation",
          subcategory="mqtt_auth_bypass",
          local_fallback="mqtt_topic_bruteforce:run",
      ),
  ]

  def run(target_ip, port=1883, duration=60, **kwargs):
      import paho.mqtt.client as mqtt
      # ... implementación ...
      return {"success": True, "message": "..."}
